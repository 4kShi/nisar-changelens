# Evaluation and failure-mode traceability

> **Status: IMPLEMENTATION (NASA Space Apps 2026, started 14 Nov 2026 00:00 ICT; authorized by project owner Trung).**

The five criteria below come from the owner brief. Current 2026 judging guide
was not obtained; no official weights are asserted. Reconcile the matrix with
that guide before submission.

| Criterion | Planned feature and value | Acceptance / evidence |
|---|---|---|
| Impact | Public plain-language map removes access and interpretation barriers | Anonymous flow, explanation of observed/hypothesized change; no claimed measured user benefit |
| Creativity | Compatibility gates and evidence storytelling embedded in viewer | User sees why a pair is accepted/rejected and how interpretation is supported |
| Validity | Authentic NISAR, explainable baseline, provenance and uncertainty | All science gates pass, independent contextual evidence for any physical claim |
| Relevance | NISAR central to surface-change exploration | Actual selected challenge resource mapped to granules and displayed comparison |
| Presentation | Focused, accessible map and stable curated public release | Anonymous/mobile/keyboard checks; clear concise English demo and reproduction record |

| Failure mode | Safeguard | Acceptance |
|---|---|---|
| 1 AI without justification | No AI mandatory; evidence-gated P2 | Compatibility/license/baseline benefit established before use |
| 2 No simple baseline | Signed calibrated comparison first | Complex method assessed on same support/reference |
| 3 Undisclosed synthetic data | Only honest empty schematic in preparation | Every fixture labeled; no synthetic scientific result claimed |
| 4 Misleading metrics | Appropriate dated independent evaluation | Denominator/splits/reference uncertainty disclosed or metrics omitted |
| 5 Ignoring uncertainty | Persistent limitations and evidence levels | No invented confidence/flood certainty |
| 6 Missing citations | Manifest provenance and attribution | Every observation, transformation and external source traceable |
| 7 Too many incomplete features | P0 freeze before P1/P2 | One valid study completed before extension |
| 8 Irreproducible demo | Immutable release, locks and receipts | Clean independent build and approved data replay |
| 9 Challenge mismatch | Official resource/challenge verification gate | Actual NISAR used and selected brief addressed |
